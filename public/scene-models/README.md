# 2D 电网场景 · 三方案预览

在本地网站打开 `/scene.html` 可切换风格、事故阶段、动效、背景融合及三案对比。这里的 SVG 是可直接在浏览器打开的独立模型文件，内含当前阶段的 CSS 动效，不依赖外部资源。

## 风格
- `line` / A：工业线稿，结构清晰，适合专业讲解与背景融合。
- `pixel` / B：黑白块状与阶梯运动，接近小恐龙式像素剪影。
- `layered` / C：灰蓝远景、设备层次、负荷灯光，适合夜景氛围。

三案共享设备位置和状态，各自包含七个阶段，共21份SVG。

## 阶段
0. normal：事故前正常运行。
1. fault：短时雷击与线路扰动、电源异常出力损失。
2. cascade：分布式电源进一步脱网，频率响应支撑。
3. defence：低频减载柜动作，示意支路 A/B 断开。
4. stable：系统趋稳，但 A/B 仍未复电。
5. restore：A 接回并逐步亮灯，B 仍等待。
6. restored：A/B 供电均恢复；不假设故障电源全部恢复。

## 专业边界
依据 National Grid ESO《Technical Report on the events of 9 August 2019》摘要及事故过程，结合既有 PPT 时间线。原文：https://www.ofgem.gov.uk/sites/default/files/docs/2019/09/eso_technical_report_-_final.pdf

雷击故障由保护快速清除，线路约20秒后恢复。短动画为时间压缩；导线颤动、照明波动、A/B顺序、设备布局和建筑比例都是教学示意，不表示机械故障或真实网络拓扑。实际低频减载切除约5%需求，插画不按这一比例画建筑。风机叶片不会因为出力骤降瞬时停止。没有虚构倒塔、爆炸或现场抢修操作。

图中聚合电源、变流器、开关和电池柜均为功能图标，不是可制造的电路图或 CAD 模型。本次不需要 ANSYS / MATLAB 等专业软件，原数值仿真不变。
